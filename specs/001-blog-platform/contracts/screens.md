# Screen Contract: 개인 블로그 서비스 (MVP)

> 화면 목록과 화면마다 꼭 지켜야 할 상태·동작이다. 문구는 원천 문서 `안내 문구` 표를 따른다.
> 주소는 가안이다. 모든 화면은 폭 360px 이상에서 가로 스크롤 없이 쓸 수 있어야 한다(FR-052).

## 공통 머리글

- 로그아웃 상태: 로고, 검색창, `로그인`, `회원가입`
- 로그인 상태: 로고, 검색창, `글쓰기`, 사용자 메뉴(닉네임 + 새 댓글 숫자 → `내 블로그`, `블로그 관리`, `마이페이지`, `로그아웃`) (FR-049, Clarifications)
- 로그인 창(모달): 이메일, 비밀번호, `비밀번호를 잊으셨나요?`. 회원 전용 기능을 누른 비회원에게 뜨고, 로그인 후 원래 하려던 화면으로 돌아간다(FR-015).

## 방문자 화면

| 화면 | 주소 | 꼭 보여야 할 것 | 상태별 처리 | FR |
|---|---|---|---|---|
| 첫 화면 | `/` | 검색창, 최근 공개 글 목록(전체 블로그, 10개씩) `(새로 정함)` | 글 없음: "글이 없습니다" | FR-034, 037 |
| 블로그 | `/blogs/{id}` | 블로그 이름·소개, 분류 목록(순서·글 수), "N개의 글", 글 목록, 페이지 번호 | 주인이면 비공개 글에 "비공개" 표시, 빈 목록에 "첫 글을 써 보세요" + `글쓰기` | FR-022, 026, 033~035 |
| 분류별 목록 | `/blogs/{id}?category={cid}` | 위와 같고 선택한 분류 강조, 페이지를 넘겨도 선택 유지 | | FR-034 |
| 글 상세 | `/posts/{id}` | 분류, 제목, 블로그 이름, 작성 시각, (수정 시각), 본문(마크다운 변환), 태그, 좋아요(개수·내 상태), 이전/다음 글, `목록으로`, 댓글 목록·입력칸 | 없는 글·남의 비공개 글: "존재하지 않는 글입니다". 작성자만 `수정`·`삭제`. 비회원 댓글칸 대신 "로그인한 회원만 댓글을 쓸 수 있습니다" + 로그인 버튼 | FR-031, 032, 038~040 |
| 검색 결과 | `/search?q=` | "검색 결과 N건", 각 결과의 블로그 이름·분류·작성일·제목·미리보기, 검색어가 남은 검색창 | 2자 미만: "검색어를 2자 이상 입력해 주세요", 없음: "검색 결과가 없습니다" | FR-036 |
| 태그별 목록 | `/tags/{name}` | 그 태그의 공개 글 목록 | | FR-041 |

## 가입·로그인 화면

| 화면 | 주소 | 꼭 보여야 할 것 | 상태별 처리 | FR |
|---|---|---|---|---|
| 회원가입 | `/signup` | 닉네임, 이메일, `인증번호 받기`, 인증번호, `확인`, 비밀번호(규칙 4개 실시간 체크), 비밀번호 확인, `가입하기` | 형식이 맞아야 `인증번호 받기` 활성화. 인증 완료 후 이메일 칸 잠금 + `이메일 변경`. 다시 받기 남은 대기 시간 표시. 모든 조건 충족 전 `가입하기` 비활성 | FR-001~009 |
| 로그인 | `/login` | 이메일, 비밀번호, `비밀번호를 잊으셨나요?` | 실패: "이메일 또는 비밀번호가 올바르지 않습니다". 잠금: "{N}분 뒤에 다시 시도해 주세요" | FR-010~012 |
| 비밀번호 찾기 | `/password-reset` | 이메일, `인증번호 받기`, 인증번호, `확인`, 새 비밀번호·확인, `변경하기` | 로그인 상태면 접근 불가(첫 화면으로). 요청 후 항상 같은 안내. 완료 후 로그인 화면 | FR-020, 021 |

## 회원 화면

| 화면 | 주소 | 꼭 보여야 할 것 | 상태별 처리 | FR |
|---|---|---|---|---|
| 글쓰기 / 글 수정 | `/write`, `/posts/{id}/edit` | 제목, 분류(기본: 마지막 분류), 공개 여부(기본 공개), 마크다운 본문 + 이미지 올리기, 태그(최대 5개), `저장` | 저장 중 버튼 잠금, 실패 시 입력 유지, 이탈 확인, 비공개→공개 확인, 남의 글 수정 주소: "존재하지 않는 글입니다" | FR-027~030, 033, 041, 043 |
| 마이페이지 | `/me` | 탭: 내 정보(이메일 읽기 전용, 닉네임, 소개, 가입일) / 비밀번호 변경 / 회원 탈퇴, `내 블로그` 바로가기 | 바뀐 게 없으면 저장 비활성, 이탈 확인. 탈퇴: 삭제·보존 안내 + 확인 체크 + 최종 확인 | FR-016~019 |

## 블로그 관리 화면 (`/manage`) — 블로그 주인만

왼쪽 메뉴: 블로그 이름, `내 블로그 보기`, `글쓰기`, 대시보드 / 글 관리 / 분류 관리 / 댓글 관리(새 댓글 숫자) / 통계 / 설정. 좁은 화면에서는 메뉴를 위쪽 가로 목록으로 바꾼다 `(새로 정함)`.

| 화면 | 꼭 보여야 할 것 | 상태별 처리 | FR |
|---|---|---|---|
| 대시보드 | 조회수·방문자(오늘·어제·누적), 새 댓글 수 + `댓글 보기`, 30일 선 그래프 + `통계 더 보기`, 인기 글 5, 최근 글 5 | 데이터 없음: 0과 안내 문구 | FR-045 |
| 글 관리 | 공개 여부·분류 거르기, 표(제목, 분류, 작성일, 공개 여부, 조회수, 댓글 수), 보기·수정·삭제, `글쓰기` | "아직 쓴 글이 없습니다" / "글이 없습니다" | FR-046 |
| 분류 관리 | 순서대로 색 점·이름·글 수, 이름 변경, 위·아래, 삭제, 새 분류 입력칸, 하단 고정 안내 | 삭제 불가: "이 분류에 글이 {N}개 있어 삭제할 수 없습니다…" | FR-047 |
| 댓글 관리 | 최신순, 작성자(탈퇴 시 "탈퇴한 사용자"), 시각, 내용 50자, 글 제목 링크(댓글 위치로), `NEW`, 삭제 | 열면 읽음 처리. 없음: "아직 달린 댓글이 없습니다" | FR-048, 049 |
| 통계 | 7일/30일 선택(기본 30), 조회수·방문자 그래프, 댓글 수 그래프, 마우스를 올리면 그날 숫자 | | FR-051 |
| 설정 | 블로그 이름, 소개 + "n/200" | 이름 없음: "블로그 이름을 입력해 주세요" | FR-022 |
