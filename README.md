# 블로그 프로젝트 문서

블로그 서비스의 요구사항과 설계 문서를 모아 두는 저장소입니다. 코드는 [my-blog-home/blog-app](https://github.com/my-blog-home/blog-app)에 있습니다.

| 위치 | 내용 |
|---|---|
| `docs/상세/` | 기능별 상세 요구사항 (CF / BM / NF) |
| `docs/가이드/` | 기술 설명과 아키텍처 그림 |
| `specs/` | Spec Kit 형식의 요구사항 (spec.md) |
| `.specify/` | Spec Kit 설정과 프로젝트 원칙 (constitution) |
| `.claude/skills/` | Claude Code에서 쓰는 Spec Kit 명령 (`/speckit-*`) |
